About this project

Promotion Predictor uses the IBM HR Analytics dataset to predict whether an employee is likely promoted (YearsSinceLastPromotion = 0) or not. The model uses job, satisfaction, tenure, and demographic features with a Logistic Regression pipeline (StandardScaler + OneHotEncoder).

How it works
  1. Target — Promoted = 1 if YearsSinceLastPromotion is 0, else 0.
  2. Features — All columns except Promoted, YearsSinceLastPromotion, and EmployeeNumber; numerical columns are scaled, categorical one-hot encoded.
  3. Model — Preprocessor + Logistic Regression, trained on 80% of the data.
  4. Predict — Enter employee attributes in Predict promotion to get a promotion probability.

The Dashboard below summarizes the dataset. Use Predict promotion to score an employee profile.
